# @wikialisa/skeleton

> Part of the [WikiAlisa](https://axvn.vn) UI component library.

## Installation

```bash
npm install @wikialisa/skeleton
# or
yarn add @wikialisa/skeleton
# or
pnpm add @wikialisa/skeleton
```

## Usage

```ts
import { version } from "@wikialisa/skeleton";
```
